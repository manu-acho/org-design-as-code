# Public Project Status

**Status date:** 8 November 2026

**Programme stage:** Empirical pilot, Week 6 complete

## Overview

Enterprise Software as Codified Organisation Design is developing a theory-led and evidence-controlled approach for studying how enterprise-software reference architectures represent organisational work. SAP S/4HANA Cloud Public Edition is the instrumental case for the first empirical study, with Procure-to-Pay, Order-to-Cash, and Record-to-Report providing the initial process comparison.

The programme has a mature research design, nine completed literature-stream drafts, and a controlled empirical pilot for SAP S/4HANA Cloud Public Edition 2608 in Switzerland. The Week 6 coding pilot is complete. The project does not claim findings about implemented systems, user behaviour, organisational performance, or realised transformation.

## Completed foundations

The project has established:

- a primary research question and five supporting questions;
- a distinction among encoded architecture, implemented configuration, and enacted practice;
- a controlled research protocol for source selection, provenance, release management, and evidence capture;
- a two-stage coding approach separating software observations from theoretical interpretation;
- analytical structures for within-process analysis, cross-process comparison, rival interpretations, and negative cases;
- detailed literature reviews for all nine streams in the shared literature map;
- a shared bibliography and literature map designed to support research papers, the monograph, and the course without duplicating literature work;
- manuscript, book, course, evidence-register, coding-matrix, and research-memo structures.

## Current priorities

The next phase has three connected priorities:

1. Consolidate the nine completed literature streams into one cumulative theoretical argument and complete outstanding page-level acquisition checks.
2. Replace overview-level evidence bundles with exact page, step, branch, rule, and object-state segments where consequential claims are proposed.
3. Complete the J45 within-process coding and mechanism map before proceeding to BD9 and J58.

Exact editions and versions of record that are required for publication-level page citation will continue to be acquired and checked alongside this work.

## Intended deliverables

The programme is designed to produce:

- nine detailed literature streams and a consolidated literature review;
- a release-controlled SAP reference-architecture corpus;
- an auditable coding framework and analytical evidence base;
- research papers on software as codified organisation design and related implementation questions;
- a research monograph on enterprise software, coordination, processes, and transformation;
- a postgraduate course with controlled undergraduate and executive pathways;
- later comparative and applied studies built from the same verified theoretical foundation.

## Evidence boundary

The current phase can establish what official reference architecture represents, permits, requires, or constrains. It cannot establish what a customer configured, how participants performed the work, whether controls were effective, or whether the system produced organisational benefits.

Public outputs will preserve this boundary throughout collection, analysis, and publication.

## Next readiness gate

The Week 6 coding gate has passed with an explicit source-granularity condition. The next readiness gate is an evidence-backed J45 within-process memo and mechanism map in which every consequential interpretation traces to an exact source location and rival explanation.
