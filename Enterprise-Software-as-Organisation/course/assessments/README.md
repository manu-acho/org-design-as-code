# Assessments

This directory will contain assignment briefs, assessment rubrics, marking guidance, moderation records, and approved adaptations.

## Planned assessment set

- analytical portfolio;
- theory comparison paper;
- process architecture analysis;
- integrative comparative project;
- oral defence or presentation rubric.

The provisional strategy and weighting are defined in `../04_Assessment_Strategy.md`. Institutional versions must record credit level, regulations, word counts, reassessment arrangements, group-work rules, and approved AI-use policy.

Use [ASSESSMENT_TEMPLATE.md](ASSESSMENT_TEMPLATE.md) to develop each assessment.
