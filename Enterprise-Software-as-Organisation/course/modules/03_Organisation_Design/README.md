# Module 3: Organisation Design

## Status

**Stage:** Scaffold with verified theory base  
**Teaching-ready:** No

## Organisational problem

Collective work must be divided into specialised contributions and integrated into a functioning whole. The module explains how structure, coordination, information, and decision arrangements address this paired problem.

## Learning outcomes

Students should be able to:

1. distinguish differentiation from integration;
2. explain contingency, configuration, complementarity, fit, and equifinality;
3. distinguish technical from organisational modularity;
4. analyse a configuration rather than an isolated software feature;
5. distinguish architectural coherence, implementation fit, and enacted fit.
