# Module 10: Comparative Process Analysis

## Status

**Stage:** Complete bounded draft package for Week 12. Teaching, assessment and rights review pending.

**Teaching-ready:** No

## Organisational problem

An isolated process cannot establish whether a mechanism is recurrent, contingent, or process-specific. The module integrates the course by comparing configurations across end-to-end processes.

## Learning outcomes

Students should be able to:

1. compare dependencies and mechanisms across controlled process scopes;
2. distinguish recurrence from superficial similarity;
3. use negative cases and rival explanations;
4. evaluate candidate software organisational primitives cautiously;
5. defend a comparative conclusion and its evidence boundary.
