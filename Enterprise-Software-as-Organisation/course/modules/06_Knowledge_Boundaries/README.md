# Module 6: Knowledge Boundaries

## Status

**Stage:** Complete first draft package for Week 8. Teaching and rights review pending.

**Teaching-ready:** No

## Organisational problem

Actors can share data while interpreting it differently or pursuing conflicting interests. The module explains why technical integration may not resolve semantic and pragmatic coordination problems.

## Learning outcomes

After working through this module, you can:

1. distinguish knowledge transfer, translation, and transformation;
2. explain boundary objects and common ground;
3. identify semantic and interest-based tensions around shared representations;
4. analyse what a master or transaction object may coordinate and what it cannot settle;
5. specify evidence needed to demonstrate shared understanding.
