# Module 1: Enterprise Software and Organisation

## Status

**Stage:** Scaffold  
**Teaching-ready:** No

## Organisational problem

Enterprise software is commonly treated as either technology or a process tool. The module asks what can be learned by treating its reference architecture as a representation of organisational order.

## Learning outcomes

Students should be able to:

1. explain the concept of enterprise software as codified organisation design;
2. distinguish encoded logic, implemented configuration, enacted practice, and outcomes;
3. classify claims according to the evidence required to support them;
4. explain the candidate concept of a software organisational primitive without treating it as established.
