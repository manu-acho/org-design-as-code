## Organisational problem

Organisations must make choices despite limited attention, incomplete information, finite time, and unequal authority. The module examines how architecture distributes premises, programmes, choice, and discretion.

## Learning outcomes

After working through this module, you can:

1. explain bounded rationality, satisficing, decision premises, and programmes;
2. distinguish calculation, recommendation, decision, authorisation, execution, and automation;
3. identify factual and value premises in a documented arrangement;
4. distinguish formal permission from accepted and effective authority;
5. trace how automation may relocate discretion.
