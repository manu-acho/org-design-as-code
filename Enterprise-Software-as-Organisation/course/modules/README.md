# Module Development

The ten modules form the postgraduate master curriculum. Each module folder contains a brief now and will later contain student lessons, seminar plans, activities, instructor notes, and links to verified cases.

## Required module files

| File | Purpose |
|---|---|
| `README.md` | Scope, outcomes, source route, activities, and development status |
| `01_Student_Lesson.md` | Accessible, complete teaching chapter |
| `02_Seminar_and_Activities.md` | Questions, exercises, and application guidance |
| `03_Instructor_Notes.md` | Teaching sequence, misconceptions, boundaries, and solutions |
| `04_Readings.md` | Required and optional readings with verification and access status |

Only `README.md` is created during the architecture stage. The remaining files should be added when a module enters active content development.

## Module content sequence

Every student lesson should follow:

1. organisational problem;
2. concrete process or artefact;
3. concept and plain-language definition;
4. connection among relevant theorists;
5. analytical application;
6. rival interpretation;
7. evidence boundary;
8. summary and formative check.

Use [the module template](MODULE_TEMPLATE.md) when developing or reviewing a module.
