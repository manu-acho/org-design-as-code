# Course Modules

The ten modules form the postgraduate master curriculum. Each has a first draft package. Start with [Module 1](01_Enterprise_Software_and_Organisation/README.md) and follow the [student route](../START_HERE.md) for the sequence.

## How to study a module

Open the module's **Start here** section to find the lesson, reading pack, case and exercise. Each lesson starts with a problem, introduces the concepts through a concrete example and returns to the case to compare interpretations and check what the evidence can support. Use the final check to see what you can explain without looking back.
