**Stage:** Scaffold pending dedicated literature stream

## Organisational problem

Organisations must allocate legitimate decision rights, monitor conduct and outcomes, permit intervention, and establish answerability. These operations overlap with coordination and decision-making but are not identical to them.

## Learning outcomes

Students should be able to:

1. distinguish permission, responsibility, authority, accountability, and control;
2. identify standards, monitoring, comparison, intervention, and consequence structures;
3. analyse approvals as possible decisions, gates, acknowledgements, or legitimacy devices;
4. distinguish traceability from accountability;
5. state the evidential limits of formal governance artefacts.
