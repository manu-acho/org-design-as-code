# Module 9: SAP Activate and Transformation

## Status

**Stage:** Scaffold with certification-learning base  
**Teaching-ready:** No

## Organisational problem

Reference architecture enters organisations through scoping, Fit-to-Standard, configuration, extension, integration, data migration, and change. The module examines these activities as potential sites of organisational design choice without presuming their empirical character.

## Learning outcomes

Students should be able to:

1. explain the principal phases and workstreams of SAP Activate;
2. distinguish reference design from implemented configuration;
3. identify organisational questions within Fit-to-Standard discussions;
4. analyse tensions among standardisation, local variation, control, and discretion;
5. formulate evidence requirements for claims about transformation outcomes.
