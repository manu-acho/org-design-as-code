# Module 2: End-to-End Processes

## Status

**Stage:** Scaffold  
**Teaching-ready:** No

## Organisational problem

End-to-end work crosses functions, roles, information objects, and system boundaries. Students need a reliable way to reconstruct that work before applying organisation theory.

## Learning outcomes

Students should be able to:

1. identify activities, actors, objects, events, states, and outcomes;
2. distinguish a process boundary from an organisational or software boundary;
3. reconstruct a documented process without assuming that it describes enacted work;
4. explain the principal P2P, O2C, R2R, and Recruit to Retire domains at an orientation level.
