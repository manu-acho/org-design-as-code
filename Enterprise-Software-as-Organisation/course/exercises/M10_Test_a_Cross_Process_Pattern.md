# Studio CP-EX-01: Can a common rework pattern survive the evidence?

**Module 10 · Week 12 · Formative rehearsal for the comparative project**

**Preparation:** Read the [lesson](../modules/10_Comparative_Process_Analysis/01_Student_Lesson.md), then allow a further 30 minutes for the [dossier](../cases/M10_Three_Processes_Comparative_Dossier.md). Use the A cards for orientation. Note one initial observation per B case; develop the full comparison in class before reading any instructor answer.

**Starting claim:** Every documented return sends the same object back to its creator, and a revised object always re-enters approval.

| Studio stage | Time | Task |
|---|---:|---|
| Reconstruct | 10 min | Map one return branch per case. Identify initiator, object, recipient, reason, continuation and condition. Cite exact locators. |
| Compare | 10 min | Record what is recurrent, different or unknown. For B4, say whether it contradicts the exact claim or only limits a broader one. |
| Challenge | 10 min | Test the interface-convention rival and the inference that a loop shows mutual adjustment. Identify a source detail or missing observation that matters for each. |
| Rewrite and defend | 10 min | Write a bounded replacement claim. Exchange with another group; defend it against its hardest case and name the evidence that would change your conclusion. |
