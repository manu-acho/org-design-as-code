# Exercises

Exercises build analytical capability progressively. Each exercise must identify its module, learning outcomes, estimated time, prerequisite knowledge, evidence status, and guidance for feedback.

## Planned sequence

1. Observation versus interpretation
2. Process boundary reconstruction
3. Dependency identification
4. Dependency-mechanism matching
5. Mechanism versus integrative condition
6. Information path and visibility analysis
7. Knowledge-boundary analysis
8. Decision-premise tracing
9. Permission, authority, and accountability distinctions
10. Cross-process comparison and negative-case search
