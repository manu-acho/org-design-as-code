# Exercise GC-EX-01: Test a control and an accountability claim

**Module 8 · Postgraduate · Formative portfolio practice**

**Preparation:** Read the [lesson](../modules/08_Governance_and_Control/01_Student_Lesson.md) and the [J58 cards and fictional trace](../cases/M08_J58_Verification_and_Accountability.md). **In class:** 35 minutes for tasks 1 to 3. **After class:** task 4 is part of the portfolio reflection.

1. **Trace the documented control.** Map the standard or scope, observable state, represented review and possible intervention. Identify which J58 card supports each observation. Keep forwarding, approval and rejection separate. Explain why the direct route limits the claim about the verification branch without proving a bypass.
2. **Challenge the fictional trace.** State two things it records and two it cannot establish. Compare substantive review with procedural acknowledgement. Identify one additional source that would help distinguish them and one check that would address segregation of duties.
3. **Design and test an exception.** Choose between an eligible substitute and holding and escalating. If proposing an override, identify the rule it would change and the limits it must preserve. Draft expected results for an eligible substitute, an ineligible substitute, a self-approval attempt and an edited entry. In the debrief, discuss how to test whether a different route is a legitimate alternative or a bypass.
4. **After class: design an accountability review.** Name the actor, the conduct they must explain and the forum's remit. Write one question the forum should ask, one finding the available evidence would justify, and one action it could require and follow up. Explain why a log field alone would not achieve this.

**Submit:** The control map or table with a text equivalent and four-row test matrix from class, plus 180 to 250 words of portfolio reasoning, including task 4. Identify the evidence level for each claim: documented reference, fictional stipulation, proposed configuration test or evidence still needed from practice.

| Criterion | A strong answer |
|---|---|
| Traceability | Uses precise locators and does not join separate reference procedures into a live trace. |
| Control reasoning | Connects a specific standard to monitoring, comparison and an intervention or gap. |
| Authority and exception | Separates technical permission, policy entitlement, replacement of a reviewer and bypass of a rule. |
| Accountability and tests | Specifies a forum with the ability to question and follow up; defines tests with observable expected results. |

This exercise rehearses programme outcomes 2, 3, 8, 9, 10, 11 and 12 for the [weekly analytical portfolio](../04_Assessment_Strategy.md#weekly-analytical-portfolio).
