# Reading Packs

This directory records course reading routes. It should not duplicate copyrighted source files or create a bibliography separate from `../../references/`.

Start with the [Module 1 orientation pack](M01_Enterprise_Software_and_Organisation.md), then the [Module 2 process pack](M02_End_to_End_Processes.md). The [Module 10 capstone pack](M10_Comparative_Process_Analysis.md) links the comparative method, scholarship and source locators.

## Reading register fields

| Field | Purpose |
|---|---|
| Module | Curriculum location |
| Full reference key | Link to the shared bibliography |
| Reading role | Orientation, essential theory, application, boundary, or advanced |
| Required or optional | Student expectation |
| Access level | Full text, abstract, metadata, or unresolved |
| Verification status | Checked, partially checked, or pending |
| Pages or sections | Assigned scope |
| Teaching rationale | Why the source is included |
| Accessibility support | Guidance required for difficult material |
| Rights route | Library link, open access, licensed platform, or citation only |

Reading routes are available for [Module 3: Organisation Design](M03_Organisation_Design.md), [Module 4: Coordination and Interdependence](M04_Coordination_and_Interdependence.md), [Module 5: Information Processing](M05_Information_Processing.md), [Module 6: Knowledge Boundaries](M06_Knowledge_Boundaries.md), [Module 7: Decision Theory](M07_Decision_Theory.md), [Module 8: Governance and Control](M08_Governance_and_Control.md), and [Module 9: SAP Activate and Transformation](M09_Activate_and_Transformation.md).
