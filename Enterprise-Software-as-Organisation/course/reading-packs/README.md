# Reading Packs

This directory records course reading routes. It should not duplicate copyrighted source files or create a bibliography separate from `../../references/`.

## Reading register fields

| Field | Purpose |
|---|---|
| Module | Curriculum location |
| Full reference key | Link to the shared bibliography |
| Reading role | Orientation, essential theory, application, boundary, or advanced |
| Required or optional | Student expectation |
| Access level | Full text, abstract, metadata, or unresolved |
| Verification status | Checked, partially checked, or pending |
| Pages or sections | Assigned scope |
| Teaching rationale | Why the source is included |
| Accessibility support | Guidance required for difficult material |
| Rights route | Library link, open access, licensed platform, or citation only |

The first register will be created when Module 1 enters active development.
