# Slides

Slide decks will be created only as modules enter active development. Slides support teaching but do not replace the student lesson or source record.

## Slide principles

- one central idea per slide;
- descriptive titles that communicate the argument;
- readable diagrams rather than decorative graphics;
- citations on the slide containing the claim;
- explicit labels for illustrative and empirical examples;
- visible evidence boundaries where a diagram could invite overclaiming;
- accessible colour, contrast, font size, and text alternatives;
- no screenshots without provenance and permission review.

Each deck should link to its module version and record the date of source verification.
