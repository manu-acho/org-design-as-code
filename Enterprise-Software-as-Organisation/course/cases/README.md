# Teaching Cases

This directory will contain verified process and architecture cases. Cases are teaching arrangements built from controlled evidence, not substitutes for the research corpus.

## Planned case families

- P2P: sequence, matching, approval, block, and exception handling
- O2C: customer-facing hand-offs, fulfilment, credit, billing, and visibility
- R2R: shared representations, control, close, consolidation, and reporting
- Recruit to Retire: lifecycle roles, information, authority, and cross-functional dependence
- Cross-process cases: recurring primitives and contrasting configurations

No case is currently teaching-ready because the target SAP release and empirical process scope remain unfrozen.

Use [CASE_TEMPLATE.md](CASE_TEMPLATE.md) for every case. Do not copy source artefacts into this directory when they belong in the controlled corpus.
