# Data Workspace

Copy templates before use; never edit raw captures. Register a source before creating evidence segments or coding. Keep licensed SAP content outside a public repository when required and store only permissible metadata/locators here. IDs and procedures are defined in `../07_Data_Collection_Protocol.md`.

The populated 2608 Swiss corpus register, evidence log, Week 6 sampling frame, and pilot coding matrix are maintained in the Git-ignored private corpus. The files in this public directory remain reusable schemas rather than empirical data.
