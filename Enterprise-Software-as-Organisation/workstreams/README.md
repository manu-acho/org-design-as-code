# Empirical Workstreams

This directory contains bounded empirical studies that reuse the programme's shared theoretical foundation without altering or duplicating it.

## Separation of concerns

The programme has three distinct layers:

1. `literature/` and `03_Literature_Map.md` contain the shared nine-stream theoretical foundation.
2. Each directory under `workstreams/` contains a case-specific research design, contextual literature, evidence protocol, ethics controls, and status record.
3. `paper/`, `book/`, and `course/` translate verified theory and evidence into outputs only after the relevant evidence gate has been passed.

A workstream may reuse concepts from the shared literature. It must not create a parallel review of the same theory. Literature that is specific to an industry, regulatory setting, organisational field, or case belongs inside that workstream's `context-literature/` directory.
