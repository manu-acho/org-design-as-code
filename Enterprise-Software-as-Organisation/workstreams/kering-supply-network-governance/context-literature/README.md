# Context-Specific Literature

## Purpose

This directory contains only the scholarship needed to interpret the Kering workstream's industry, network, regulatory, and inter-organisational setting. The shared nine-stream review remains authoritative for the programme's general theoretical foundation.

When a source contributes principally to organisation design, coordination, decision theory, enterprise systems, routines, materiality, digital infrastructure, governance, or process architecture, it must be registered in the shared literature system. This directory should record the case-specific application rather than reproduce the full review.

## Candidate frameworks from the proposal

The attached proposal names global value-chain governance, agency theory, transaction-cost economics, and dynamic capabilities. These are candidate lenses only. Each must pass a bounded source search and conceptual-necessity test before inclusion.

Agency theory, transaction-cost economics, and dynamic capabilities should not automatically become new programme streams. They should be used only where they explain a defined part of the Kering research question better than the existing foundation.

## Non-duplication rule

For every retained contextual source, record:

1. the Kering-specific question it answers;
2. the shared stream or streams it connects to;
3. whether it adds a genuinely new concept or only a domain application;
4. its evidence-access level;
5. the claim boundary it supports;
6. whether it should also enter the shared bibliography.

Use [Context_Literature_Register.csv](Context_Literature_Register.csv) for this purpose.

## Review sequence

1. Complete a scoping search for each domain cluster.
2. Verify bibliographic metadata and full-text access.
3. Read foundational and directly relevant sources before synthesis.
4. Build a crosswalk to the shared streams.
5. Write a bounded contextual synthesis organised by the research problem, not by author summaries.
6. Audit the synthesis for unsupported Kering, legal, technological, and outcome claims.
