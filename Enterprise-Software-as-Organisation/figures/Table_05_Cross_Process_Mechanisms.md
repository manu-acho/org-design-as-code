# Table 5. How selected reference procedures organise work

The table compares documented operations, not equivalent end-to-end flows. Evidence IDs resolve to public SAP pages in [Table 7](Table_07_Findings_Source_Locators.md).

| Mechanism | J45: procurement | BD9: sale from stock | J58: accounting and close | Boundary or contrast |
|---|---|---|---|---|
| Record-dependent action | Purchase-order items supply the referenced invoice (J45-W07-16). | An earlier order helps select delivery work; confirmed quantities feed billing in the optional route (BD9-W08-08, BD9-W08-12). | An earlier clearing-entry identifier selects the correction target (J58-W08-11). | The non-PO invoice uses accounting inputs (J45-W07-19). Object targeting is not the same as data transfer. |
| Conditional decision processing | A condition routes PO release; automatic release is also documented (J45-W07-06, J45-W07-08, J45-W07-09). | Configured sales workflow precedes the represented decision; a separate workflow concerns preliminary billing (BD9-W08-04, BD9-W08-05, BD9-W08-16). | In the verified branch, a submitted entry is approved and posted (J58-W08-05). | Direct posting exists (J58-W08-01). The cases do not establish one threshold, universal human approval or effective authority. |
| Formal return | Request and creator instruction are shown, not completion (J45-W07-11). | An inbox response or change is available (BD9-W08-06, BD9-W08-07). | Edit and resubmission after rejection are documented (J58-W08-07). | No case establishes negotiated mutual adjustment. |
| Scheduling and inspection | Requisition conversion can be scheduled and its result inspected (J45-W07-05). | Scheduled delivery creation and billing release have logs (BD9-W08-17). | Year-end carryforward and its earlier scheduled alternative distinguish test and productive runs (J58-W08-17). | Scheduling, execution and review are not always performed by the same actor or observed at all. |
| Visibility and consequential use | An overdue-items view makes a condition visible (J45-W07-22). | A preview does not show dispatch; confirmed quantities can feed billing (BD9-W08-14, BD9-W08-12). | A validation-results view exposes detail; manual clearing specifies a condition and expected state change (J58-W08-15, J58-W08-10). | Inspection, operative input and intervention are different. None establishes effective control or accountability. |
