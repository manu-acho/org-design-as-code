# Enterprise Software as Codified Organisation Design

This repository is a working research environment for examining how organisational coordination and governance mechanisms are encoded in enterprise software reference architectures. Its primary question is: **How are organisational coordination and governance mechanisms encoded within enterprise software reference architectures?** SAP S/4HANA Cloud Public Edition is the instrumental case; Procure-to-Pay (P2P), Order-to-Cash (O2C), and Record-to-Report (R2R) are the initial process domains.

The first paper reconstructs **encoded organisational logic** from vendor reference artefacts. It does not infer implemented configurations or enacted practices. Thompson's interdependence theory, Galbraith's information-processing view, and Mintzberg's coordination mechanisms form the main theoretical lenses. The candidate contribution—enterprise software as codified organisation design—remains to be tested.

## How to use this repository

Begin with [the research protocol](06_Research_Protocol.md), register every source in `data/Corpus_Register_Template.csv`, preserve a stable copy or locator, code evidence using [the coding manual](08_Coding_Manual.md), and record inferential steps in `memos/`. Use [the analytical framework](09_Analytical_Framework.md) to construct within-process and cross-process displays. Manuscript files in `paper/` should be updated from evidenced analytic memos, not from impressions.

The numbered files move from research framing through corpus construction, analysis, manuscript production, and execution. `literature/` holds reading instruments; `data/` contains blank empirical templates; `references/` contains verified or explicitly flagged bibliographic records; and [PROJECT_STATUS.md](PROJECT_STATUS.md) records the boundary between completed design work and outstanding empirical work.
